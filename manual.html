御守POS 説明書

お札・御守・破魔矢・絵馬・熊手などの在庫管理とレジのアプリです。

1. このアプリについて

レジ、在庫、売上、設定の4つの画面があります。商品に写真を付けて、タップで会計できます。

  • データは、お使いの端末の中だけに保存されます。インターネット上には送られません。
  • 端末ごとにデータは別々です。複数の端末で使う場合は、バックアップで移します。
  • 一度ネットにつないで開けば、そのあとは電波がなくても使えます。

2. 公開のしかた（最初に一度だけ）

「ホーム画面に追加」して全画面で使うには、アプリを https:// で始まるURLで開ける状態にする必要があります。次の2つのどちらかで、無料で用意できます。

Netlify はパソコンから、GitHub はスマホからでも作業できます。画面の文言は、サービス側の更新で変わっていることがあります。

ファイル名は変えないでください名前や置き場所が違うと、ホーム画面への追加やオフライン動作がうまくいきません。

方法A：Netlify（パソコンがあるとき・かんたん）

  1. zipファイルを展開して、ファイルが入ったフォルダを作ります。
  2. Netlify（netlify.com）で無料アカウントを作り、ログインします。
  3. サイトを新しく作る画面で、「フォルダをドラッグ＆ドロップして公開する」方法（Deploy manually / Netlify Drop）を選びます。
  4. 展開したフォルダを、そのまま画面にドロップします。
  5. 数十秒で https://〜.netlify.app というURLができます。これがアプリのURLです。
  6. サイトの設定（Site configuration）の「Site name」を変えると、URLの名前を好きなものにできます。

方法B：GitHub Pages（スマホだけでもできる）

  1. GitHub（github.com）で無料アカウントを作り、ログインします。
  2. 右上の「＋」から「New repository」を選びます。名前は omamori-pos など、好きな英数字にします。
  3. 公開設定は Public にして「Create repository」を押します。
  4. 「uploading an existing file」（または「Add file」→「Upload files」）を押します。
  5. 用意したファイルをすべて選んでアップロードし、「Commit changes」を押します。フォルダごとではなく、ファイルを直接アップロードしてください。
  6. リポジトリの「Settings」→「Pages」を開きます。
  7. 「Source」を「Deploy from a branch」にし、ブランチは main、場所は / (root) を選んで「Save」を押します。
  8. 1〜数分待ってページを開き直すと、https://ユーザー名.github.io/omamori-pos/ のようなURLが表示されます。
公開（Public）についてURLを知っている人は、誰でもアプリを開けます。ただし、公開されるのはアプリ本体だけです。商品や売上のデータは各端末の中にあり、ここには含まれません。

3. ホーム画面に追加する

できあがったURLを、使いたい端末で開きます。そのあと、次の手順で追加すると、アドレスバーのない全画面のアプリとして使えます。

iPhone・iPad

  1. 必ず Safari でURLを開きます。
  2. 画面の共有ボタン（四角から矢印が出ているマーク）を押します。
  3. 「ホーム画面に追加」を選びます。見つからないときは、一覧を下へスクロールします。
  4. 名前を確認して「追加」を押します。
  5. ホーム画面にできた鳥居のアイコンから開きます。

Android

  1. Chrome でURLを開きます。
  2. 右上の「︙」メニューから「アプリをインストール」または「ホーム画面に追加」を選びます。
  3. 確認の画面で「インストール」（または「追加」）を押します。

Windows（Edge・Chrome）

URLを開いて、アドレスバー右側のインストールのマークを押します。見当たらないときは、メニューの「アプリ」から「このサイトをアプリとしてインストール」を選びます。

最初に使う場所を決めてくださいSafariで開いたときと、ホーム画面のアイコンから開いたときでは、データが別々に保存されます。商品を登録する前に、ホーム画面に追加して、いつもそのアイコンから開くようにしてください。
オフラインで使うには追加したあと、ネットにつながった状態で、アイコンから一度アプリを開いてください。それ以降は、電波がない場所でも起動できます。

4. 使い方

レジ

  1. 上のタブ（すべて・お札・御守・破魔矢・絵馬・熊手・その他）で、商品の種類を切り替えます。
  2. 商品の写真をタップすると、カートに入ります。同じ商品をタップすると、1つずつ増えます。
  3. スマホ：画面下のバーに点数と合計が出ます。右の 会計へ ▲ を押すと、会計画面が開きます。
    iPad・タブレット（横向き）：画面の左半分に商品、右半分の左側に選択商品の一覧、右側に会計画面が、いつも出ています。縦向きでは、右側に選択商品と会計画面が上下に並びます。
  4. 会計画面に、合計の「合計金額」と、「お預かり金額」が並んで表示されます。「お預かり金額」を、テンキーで入力します。テンキーの上にある ¥1,000 ¥5,000 ¥10,000 を押すと、その金額が一度で入ります。C は全部消し、テンキーの ⌫ は1文字だけ消します。
  5. お釣りが表示されます。金額が足りていれば、会　計 ボタンが押せます。
  6. 会計が終わるとレシートが出ます。必要なら 印刷 を押します。
間違えて会計したときレシート画面の「この会計を取り消す」を押すと、売上から消えて、在庫が元に戻ります。レシートを閉じたあとは、「売上」タブの履歴にある「取消」から同じ操作ができます。

カートの中の数量は、− ＋ で変えられます。✕ で1品を削除できます。カートを空にするときは、タブレットでは「選択商品」の横の クリア、スマホでは会計画面の一番下の ✕ クリア を押します。

在庫

  • 新規商品を追加：「＋ 新規商品を追加」を押します。写真は「カメラで撮影」か「アルバムから選択」で付けられます。名前、カテゴリー、価格、在庫数を入力します。
  • 写真の変更：商品の写真をタップするか、「編集」を押します。
  • 在庫数の増減：商品の横の − ＋ で、1つずつ変えられます。
  • 価格の変更履歴：商品名の横の「履歴」を押すと、いつ、いくらから、いくらに変えたかが見られます。
  • 並び替え：「☰ 並び替えモード」を押すと、☰ が出ます。商品の☰をドラッグして順番を変えます。終わったら「✅ 並び替え完了」を押します。モードがオフの間は、並びは変わりません。
  • 削除：「削除」を押して、確認で「OK」を押します。
  • 検索：上の検索欄に商品名を入れると絞り込めます。

在庫が5個以下の商品はオレンジ、0個は赤で表示されます。上のカードで「要補充」「在庫切れ」の数が分かります。

売上

  • 期間は「全期間・今日・今週・今月・期間指定」で切り替えます。合計、件数、平均単価、グラフ、ランキングも、その期間に合わせて変わります。
  • グラフは「日別」（直近14日）と「時間帯別」があります。
  • 履歴の「取消」を押すと、その会計を消して、在庫を元に戻します。
  • 売上の全削除：画面の一番下の「⚙ 管理」を押すと、赤い枠が開きます。「長押しで全削除」を1.5秒押し続けると実行されます。この操作では在庫は戻りません。取り消せないので、実行前にバックアップを取っておくと安心です。

設定

  • レジ画面の列数：商品を横に何個並べるか（2〜6列）を選べます。スマホは2〜3列、iPadは4〜6列がおすすめです。
  • レシートの設定：社名と連絡先（住所・電話番号など）を入力すると、会計後のレシートと印刷のいちばん上に表示されます。入力は自動で保存されます。社名が空のときは「御守」と表示されます。
  • 印刷の設定：用紙サイズ（レシートロール58mm・80mm、A6・A5・A4）を選べます。「テスト印刷」で、見た目と用紙を確認できます。Windows・AndroidのChrome / Edgeでは、選んだ用紙サイズで印刷されます。iPhone・iPadでは、印刷の画面でプリンターと用紙を選びます。
  • バージョン情報：設定タブの一番下に、アプリの番号（例：Ver. 1.0.0）が表示されます。
  • 全画面：Android・Windows・iPadでは、ボタンで全画面にできます。iPhoneとiPadは、ホーム画面のアイコンから開くのが確実です。
  • バックアップ・CSV：次の章で説明します。

5. バックアップと機種変更

データは端末の中にしかありません端末をなくしたとき、Safariの履歴やWebサイトデータを消したとき、アプリを入れ直したときは、データも消えます。週に一度などで、バックアップを取っておくことをおすすめします。

バックアップを保存する

  1. 「設定」タブの ⬇ バックアップ保存 を押します。
  2. 確認画面で「OK」を押します。
  3. 共有画面が出たら、iPhone・iPadは「ファイルに保存」を選びます。保存場所（iCloud Driveなど）を選んで「保存」を押します。

保存されるのは 御守POS_バックアップ_日付.json というファイルです。商品、写真、在庫数、売上履歴、価格の変更履歴、並び順、列数、レシートの社名・連絡先・用紙の設定が入っています。

別の端末へ移す・元に戻す

  1. 新しい端末で、2章・3章のとおりにアプリを開き、ホーム画面に追加します。
  2. バックアップのファイルを、新しい端末で見られる場所に置きます（AirDrop、メール、クラウドなど）。
  3. 「設定」タブの ⬆ バックアップ復元 を押して、そのファイルを選びます。
  4. 確認画面で「OK」を押します。
復元は上書きです同じ番号の商品は、バックアップの内容に置き換わります。

CSV（Excelなどで使う）

  • ⬇ 在庫CSV書出し・⬇ 売上CSV書出し：Excelで開ける形式で保存します。売上の集計に使えます。
  • ⬆ CSV読み込み：在庫CSVを編集して読み込むと、まとめて更新できます。列は「ID, 商品名, 価格, 在庫数, カテゴリー, 絵文字, 説明」の順です。
  • IDが同じ行は上書き更新されます。IDがない・新しい行は、新しい商品として追加されます。新しく追加された商品は「その他」カテゴリーになるので、必要なら在庫タブの「編集」で変更してください。

6. アプリを更新するとき

新しい index.html などを受け取ったら、公開した場所のファイルを、同じ名前で置き換えます。

  • GitHub：リポジトリで「Add file」→「Upload files」から、同じ名前のファイルをアップロードして「Commit changes」を押します。
  • Netlify：サイトの「Deploys」の画面に、新しいフォルダをもう一度ドロップします。

アプリは、開くたびに裏で新しい版を取得して、次に開いたときに切り替わります。アプリを完全に終了して開き直す操作を、2回くり返せば、新しい版になります。商品や売上のデータは、更新しても消えません。

更新できたかどうかは、設定タブの一番下の「バージョン情報」で確認できます。更新前より番号が上がっていれば、新しい版です。

7. 困ったとき

ホーム画面に追加が出ない

iPhoneは、Safari以外のアプリでは出ないことがあります。Safariで開き直してください。Androidは、Chromeで開き、URLが https:// で始まっているか確認してください。

データが消えた・商品が空になった

Safariで開いたときと、ホーム画面のアイコンから開いたときは、データが別です。先に使っていたほうで開いていないか確認してください。それでもないときは、バックアップから復元します。

バックアップのファイルが見つからない

保存のとき、共有画面で「ファイルに保存」を選ぶと、保存場所を選べます。iPhone・iPadの「ファイル」アプリで、選んだ場所を開いてください。

写真が撮れない・選べない

端末の設定で、Safari（またはホーム画面のアプリ）にカメラと写真の利用を許可してください。

画面が古いまま・動きがおかしい

アプリを完全に終了してから開き直してください。それでも直らないときは、先にバックアップを取ってから、ホーム画面のアイコンを削除し、もう一度追加してください。そのあと、バックアップを復元します。

ボタンを押しても反応しない

確認の画面が開いていないか見てください。画面を閉じて、もう一度押します。
